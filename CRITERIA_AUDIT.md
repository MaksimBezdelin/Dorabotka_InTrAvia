## 4. Что подтверждено фактическим прогоном (2026-11-24, вечер)

- **pytest:** `75 passed, 104 skipped, 0 failed` (21.5 с); **124 маршрута**; `import app` OK.
- **Живой смоук на копии БД — 20/20:**
  - `GET /api/system/current-airport` без сессии → **200** `{"airport":"vdnh"}`;
  - логины admin/dispatcher/mcc/pilot/engineer → 200;
  - страницы диспетчера, MCC, инженера, карты, мобильный экран и локальный Leaflet → 200;
  - классификатор: «течь гидравлики» → MEL/5 matches, «двигатель не запускается» → AOG/3;
  - `/api/dispatcher/priorities` → 200; CSV журнала → 200 `text/csv`;
  - чужой GPS → **403**, свой GPS → 200;
  - создание заявки пилотом → 200; `test_options` → 200; пауза → 200.
- **Пауза трекинга:** `POST /api/v1/track` → `{"accepted":true,"applied":false,"reason":"paused"}` (бэкенд-прогон).
- **Норматив без GPS:** warning `remaining_min=3.8`, `eta_min=9.5`, `can_make_it=false`, `nearest_free` EN-001 4.3; breach `remaining_min=-1.2`.
