Шаг 1. Идентификация дефекта

Проверьте данные о дефекте, поступившие от экипажа / ACARS / технической службы. Это основа для дальнейшей оценки по MEL/CDL/AMM.

Шаг 2. Проверка по MEL / CDL

Сверьте дефект с Перечнем минимального исправного оборудования (MEL) и Перечнем допустимых отклонений конфигурации (CDL).

Шаг 3. Процедуры и категория

Для оформления отложенного дефекта (ADD) необходимо выполнить все предписанные MEL процедуры. Проверка должна быть подтверждена в техническом журнале.

Шаг 4. Проверка на повторяемость

Повторяющийся дефект — сигнал о скрытой системной проблеме. Критерий: 3+ раза за 15 сегментов полёта без успешного устранения корневой причины.

Шаг 5. Итоговое решение DCE

Финальное решение фиксируется в системе «Купол» с комментарием и подписью DCE.
