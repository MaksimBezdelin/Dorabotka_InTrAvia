# InTrAvia — обновление мобильного интерфейса инженера

Изменения затрагивают только мобильный интерфейс (`mobile/www/engineer/dashboard.html`) и его синхронизированную Android-копию в `mobile/android/app/src/main/assets/public/engineer/dashboard.html`. Компьютерный интерфейс инженера и интерфейс диспетчера не менялись.

## Что добавлено

- Полноэкранная карта на мобильном экране.
- Переключение базовой карты: обычная OpenStreetMap и спутниковая Esri World Imagery. Выбор сохраняется на устройстве.
- Плавающая сворачиваемая панель текущих задач поверх карты.
- Нижняя мобильная навигация: задачи, статистика, прошлые отчёты, профиль и выход.
- Статистика перенесена с главной карты в отдельную мобильную вкладку.
- Позиция по-прежнему поступает от GPS, а направление курсора берётся только из абсолютного датчика ориентации/магнитного компаса. При повороте телефона новый heading сразу ставится в очередь на отправку серверу с координатами последнего GPS-фикса.

## Пересборка Android

```bash
cd mobile
npm install
npx cap sync android
npx cap open android
```

Затем соберите APK в Android Studio.

## Примечания

- Компас требует датчик магнитного поля/поддержку абсолютной ориентации в Android WebView. На устройствах без такого датчика направление не сможет обновляться по компасу.
- Android может ограничивать обновления GPS при выключенном экране или в фоне. Эта версия отслеживает местоположение, пока мобильное приложение активно.
- В архив не включён локальный `.env` с секретами. Для существующего развёртывания сохраните прежний `.env`; пример переменных находится в `.env.example`.


## Компас относительно истинного севера

- На Android используется TYPE_ROTATION_VECTOR (сенсорное объединение гироскопа, акселерометра и магнитометра).
- При наличии свежей GPS-позиции Android рассчитывает магнитное склонение через GeomagneticField и переводит азимут к истинному северу.
- GPS-курс для направления стрелки не используется.
- Если TYPE_ROTATION_VECTOR недоступен, используется абсолютный резервный расчёт акселерометр + магнитометр.
- Для точного направления держите телефон в рабочем положении; при магнитных помехах выполните калибровку движением телефона восьмёркой.
