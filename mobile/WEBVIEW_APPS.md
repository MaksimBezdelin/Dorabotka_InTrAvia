# Мобильные WebView-приложения InTrAvia

Две отдельные Android-оболочки поверх существующего веб-интерфейса InTrAvia.
Нативного кода минимум: `WebView` + мост геолокации, весь интерфейс — серверные страницы.

| Приложение | Пакет | Страница | Назначение |
|---|---|---|---|
| **InTrAvia Инженер** | `ru.intravia.engineer` | `/m/engineer` | Пульт инженера: задачи, статусы, маршрут, GPS-трекинг |
| **InTrAvia Агенты** | `ru.intravia.agents` | `/m/agents` | Ввод и отправка координат других агентов, режим маяка |

## Требования

- Android 7.0+ (minSdk 24), targetSdk 36.
- Телефон и сервер в одной сети (или доступный по IP/домену).
- Сервер InTrAvia запущен (`python app.py` — порт 5000, либо `python serve.py` — порт 8080).
- Адрес сервера задаётся при первом запуске; меняется через меню **⋮ → Сервер**.

HTTP (без TLS) разрешён намеренно — стенд работает по локальной сети.
Для публикации в интернет используйте HTTPS-туннель и включите аутентификацию
(см. `SECURITY.md`).

## Сборка

Из корня репозитория:

```bash
# Инженер
cd mobile/webview-engineer
export JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"
export ANDROID_HOME="$LOCALAPPDATA/Android/Sdk"
./gradlew assembleDebug --no-daemon

# Агенты
cd ../webview-agents
./gradlew assembleDebug --no-daemon
```

Готовые APK:

- `mobile/webview-engineer/app/build/outputs/apk/debug/app-debug.apk`
- `mobile/webview-agents/app/build/outputs/apk/debug/app-debug.apk`

Установка:

```bash
adb install -r mobile/webview-engineer/app/build/outputs/apk/debug/app-debug.apk
adb install -r mobile/webview-agents/app/build/outputs/apk/debug/app-debug.apk
```

Сборки используют Gradle 9.5.0 / AGP 9.3.1 / JDK 21. Путь с кириллицей
поддержан через `android.overridePathCheck=true` в `gradle.properties`.

## Приложение инженера

1. При первом запуске приложение просит адрес сервера, например `http://192.168.1.10:5000`
   (для эмулятора — `http://10.0.2.2:5000`).
2. Выбор инженера сохраняется в `localStorage` (`intravia.mobile.engineer`).
3. Карточка активной задачи: принять/отклонить, «Сел в транспорт», «Я на месте»,
   «Начать диагностику» — через существующие API `/api/requests/<rid>/...`.
4. Маршрут и ETA — `/api/dispatcher/requests/<rid>/route`.
5. GPS: `watchPosition` отправляет точки в `POST /api/v1/track` с троттлингом;
   позиция видна диспетчеру на карте.

## Приложение агентов и режим маяка

1. Список объектов подтягивается из `GET /api/v1/agents`
   (инженеры, транспорт, воздушные суда).
2. Можно выбрать объект из списка **или** ввести произвольный `obj`.
3. Точка ставится тапом по карте либо перетаскиванием маркера, затем **Отправить** —
   одиночный `POST /api/v1/track`.
4. **Режим маяка**: выбрать один объект, интервал 1/2/5/10 с и источник
   (точка на карте или GPS устройства) → приложение непрерывно шлёт координаты
   этого агента на сервер, пока режим включён.
5. Журнал последних 40 отправок показывает ответ сервера (`accepted`, `applied`).

## Обновление в реальном времени

- `GET /api/v1/stream` — SSE-поток (`position`, `sync`, `request`).
- Любой `POST/PUT/DELETE` на `/api/` автоматически рассылает событие `sync`
  всем подключённым клиентам (`after_request` в `app.py`).
- Если SSE недоступен, страницы опрашивают сервер: инженер — 7 с, агенты — 10 с.

## Контракт трекинга

```http
POST /api/v1/track
Content-Type: application/json

{"obj": "eng_1", "lat": 55.9755, "lon": 37.4005, "t": "2026-11-23T12:00:00Z", "acc": 5, "spd": 1.2}
```

- Одна точка или пакет: `{"points": [{...}, {...}]}` (ответ — массив в том же порядке).
- `400` — некорректные `lat`/`lon`.
- `200` + `applied: false` — объект не найден в реестре.
- Алиасы: `e-01` → `eng_1`, `v-01` → `CAR-001`, позывные/бортовые номера — для ВС.

## Ограничения

- При `AUTH_REQUIRED=1` серверные API требуют сессию, а экрана входа в мобильных
  страницах пока нет: приложения рассчитаны на демо-режим (`AUTH_REQUIRED=0`) и
  доверенную локальную сеть. Контракт трекинга `/api/v1/track|stream|agents|snapshot`
  остаётся публичным и при включённой авторизации.
- Не публикуйте стенд в интернет без reverse-proxy с авторизацией.
- Геолокация запрашивается при старте; без разрешения маяк работает только
  от точки на карте.
